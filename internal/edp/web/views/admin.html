{{else if eq .Tab "google"}}

Google account connections

Configure EDP’s Google OAuth application once. Each user grants read-only access to their own Google Drive and Sheets account under My connections.

Bootstrap with GOOGLE_OAUTH_CLIENT_ID and GOOGLE_OAUTH_CLIENT_SECRET. Saved settings override these values. Changing the client credentials or public URL requires users to reconnect. Public URL is managed under Single sign-on. Google connections are separate from EDP sign-in.
