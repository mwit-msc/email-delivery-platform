# Security

Report suspected vulnerabilities privately through GitHub’s security advisory
reporting for this repository. If private reporting is unavailable, contact a
repository maintainer privately; do not put credentials or exploit details in
public issues.

Include the affected version, a minimal reproduction, impact, and any suggested
mitigation. Use synthetic recipients and test credentials.

Use HTTPS in production, keep the encryption key backed up separately, and
provide each application with its own scoped service key. Never commit `.env`,
service-account JSON, private keys, database dumps, or real recipient lists.
